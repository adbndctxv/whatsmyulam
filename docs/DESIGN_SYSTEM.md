# Design system

**Status:** specification only. No UI is built yet.

Feel: a friendly household companion, not a corporate dashboard. Clarity before cleverness.

## Colors

| Token | Value | Use |
| --- | --- | --- |
| Primary green | `#347653` | Buttons, links, brand |
| Warm cream | `#FFF8ED` | Page background |
| Dark text | `#253329` | Body text |
| Yellow accent | `#F2C66D` | Highlights, badges |
| White | `#FFFFFF` | Cards |
| Muted text | `#6B746D` | Secondary text |

Check text contrast (WCAG AA) when the UI is built, especially muted text on cream and dark text on yellow.

## Type, shape, spacing

Readable sizes (16px minimum body), generous spacing, rounded cards, subtle borders, clear icon-plus-label buttons. Avoid heavy gradients, clutter and excessive animation.

## Responsive rules

- Mobile first, then tablet and desktop.
- The **ANO ULAM NATIN?** button must be visible without scrolling through a long intro.
- Controls are at least 44px tall for touch.

## Accessibility

Labelled form controls, visible focus, keyboard-operable meal selector, useful error, loading and empty states.

## Images

Only properly licensed images with credit. Otherwise show a fallback (category icon on a cream card). No hotlinking.

## Copy

Natural Filipino or Taglish where it helps, for example "Hindi alam kung ano'ng ulam?" Do not make every label playful.
